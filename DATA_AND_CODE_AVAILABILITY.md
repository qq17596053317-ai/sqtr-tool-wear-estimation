# Data and code availability

NASA Milling, NUAA and PHM 2010 are third-party public datasets and are not
redistributed here. Original sources and the pinned UniWear commit are listed
in the root README.

This repository archives MATLAB R2024b code, derived fold-level predictions,
unit-level statistics, synthetic-degradation results, and figure source data.
The corresponding author can provide repository access to the editor and
reviewers during peer review. The repository will be made public and released
as a DOI-bearing versioned archive upon acceptance.
